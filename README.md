i decided to try to see how simple a cad can be and not be weird
# sytax
the syntax is not stable but right now it looks like \
type = [point|triangle|line]: declares a variable with type type with defualt value\
point x = [x,y,z]: declares a point with x,y,z = [x,y,z]\
line x = [p1,p2]: declares a line with an n,m of p1,p2\
triangle t = [p1,p2,p3]: declares a triangle with an a,b,c of p1,p2,p3\
